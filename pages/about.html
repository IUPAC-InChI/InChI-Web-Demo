InChI Web App

Chemical identifiers generated in your browser, never on a server.

Back to the tool

This web application runs entirely in your browser using WebAssembly. Structures you draw or paste are converted in your browser and are not sent to a server. Two things do leave your browser, both only when you ask for them: the report form sends a structure you explicitly choose to report, and a PubChem lookup sends the identifier you typed — SID 24866042 or CID 2244 — to PubChem’s PUG REST service, which returns the record. No structure of yours is sent in that request, but PubChem does see your IP address and which record you asked for. Running everything locally comes at the cost that the initial loading might take a while, since the structure editor and the InChI libraries have to be downloaded first (they would otherwise live on a server). If the application behaves unexpectedly, try clearing your browser cache and reloading the page (CTRL + F5 in most browsers). Clearing the cache helps because an update might have changed files that are now in conflict with the files in your browser cache.

Contact

If you have any questions, suggestions, or feedback, please reach out to us: inchi@ac.rwth-aachen.de. We especially encourage you to report problematic structures (please include a molfile along with a description of the problem). You can also submit an issue via our GitHub repository.
