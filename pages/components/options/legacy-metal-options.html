This version handles molecular inorganics by default. Enable this option to use the legacy salt and metal-bond handling instead. It switches molecular inorganics off and produces non-standard InChI.

In this version, "*" (Zz) atoms are always allowed outside polymers (NPZz), so there is no NPZz option to set.

The functionality for molecular inorganics is a work in progress. You can expect to encounter warnings. For an improved experience when working with inorganic structures, consider the following tips:

  • Input crystal structures as molfiles. Convert the CIF to a molfile, e.g. using Mercury (CCDC), or codcif2sdf (cod-tools).
  • In the structure editor, for donor atoms beyond nitrogen, change the valence (i.e. coordination number) of the atoms accordingly by right-clicking the corresponding atoms.
