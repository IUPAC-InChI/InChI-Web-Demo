If enabled, all hydrogens in the input structure are treated as explicit hydrogens. Reflects the doNotAddH option in the InChI command line tool. If disabled, implicit hydrogens are added to the structure before InChI generation.

Note: the Ketcher structure editor does not take this option into account, so implicit hydrogen atoms are displayed according to the Ketcher settings.

The "Zz" or "*" ("star") pseudoatom is a generic placeholder designating an entity of undefined, unknown or variable nature. It is typically used for handling polymers, but may also be used outside the polymer context with this InChI option (NPZz). See the InChI Technical Manual, section IV, "g. Zz (star, pseudo element) atoms", for details.

How to draw one: "*" pseudoatoms can be selected within the Ketcher structure editor either via the Extended Table in the right toolbar, or with the hotkey "*".
