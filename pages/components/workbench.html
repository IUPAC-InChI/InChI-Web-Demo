Not being converted — the drawing is

What you paste is converted exactly as given — the editor above only draws it, so nothing is rewritten on the way to the library. Edit the drawing and it becomes the source instead. An AuxInfo has to contain atom coordinates, or there is nothing to draw. Two inputs are the exception to converting what you gave. A PubChem identifier: the record is fetched from PubChem over the network and that is what gets converted, so the prefix is required — SID and CID number different things. And a SMILES: it carries no coordinates, so the editor lays the structure out and the molfile it produces is what gets converted — which means the stereo the library sees was drawn by the editor, not by you. A CXSMILES carrying its own coordinates keeps them.
