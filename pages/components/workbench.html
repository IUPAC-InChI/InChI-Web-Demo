Not being converted — the drawing is

What you paste is converted exactly as given — the editor above only draws it, so nothing is rewritten on the way to the library. Edit the drawing and it becomes the source instead. An AuxInfo has to contain atom coordinates, or there is nothing to draw. A PubChem identifier is the one exception to converting what you gave: the record is fetched from PubChem over the network and that is what gets converted, so the prefix is required — SID and CID number different things.
