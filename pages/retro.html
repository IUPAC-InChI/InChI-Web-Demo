What this screen does

Fill field 1 with a structure, choose an algorithm version and flags in field 2, then press ENTER. Field 3 shows the InChI split into its real layers and the InChIKey split into its three blocks.

PF7 PIN holds the current answer. Change the version or a flag and run again: field 4 shows which layers moved. Difference is carried by intensity and a > marker in the gutter, never by colour, so it survives greyscale and print.

X SYSTEM in the operator information area means a WebAssembly module is still compiling. It is roughly 1 MB per version and it is fetched the first time you select that version.
